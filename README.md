# RED FOX — СВОЯ ИГРА

Независимое оформление меню заданий RedFox в стиле современной телевизионной интеллектуальной игры.

## Подключение

Вставить в название игры RedFox:

```html
<script src="https://cdn.jsdelivr.net/gh/RedLine142/redfox-svoya-igra@main/redfox-svoya-igra.js"></script>
```

Скрипт работает только на странице списка заданий `/play/safari`. На страницах отдельных заданий, в админке и на других разделах он не запускается.

## Состав

- `redfox-svoya-igra.js` — построение игрового табло, маршруты заданий, чтение прогресса.
- `styles/main.css` — оформление, адаптивная сетка, состояния ячеек и анимации.

CSS подключается скриптом с jsDelivr. Если таблица заданий не найдена или стили не загрузились, исходный список RedFox остаётся доступным.

## Игровое поле

7 категорий × 5 номиналов:

- Школьная программа: 9010–9014
- Спорт: 9015–9019
- Хобби: 9020–9024
- Ночной дозор: 9026–9030
- Вредные привычки: 9031–9035
- Игротека: 9036–9040
- Путешествия: 9041–9045
- Суперигра: 9047

## Прогресс

Скрипт читает данные прогресса из соответствующих исходных карточек RedFox: текст вида «найдено X из Y» и/или ширину `.progress-bar`. При достижении 100% ячейка получает приглушённое монохромное оформление. Сам игровой прогресс не изменяется.

## Область действия

Скрипт не меняет серверную часть RedFox, проверку ответов, таймеры заданий или содержимое отдельных игровых страниц.
